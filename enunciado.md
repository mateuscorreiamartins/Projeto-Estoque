Desafio: Controlar a entrada e saída de produtos e materiais 

Objetivo: desenvolver uma aplicação de controle de estoque, onde será possível cadastrar um produto realizando edição para atualizar a entrada e/ou saída de mercadorias. 

Instruções: 

1. Utilize a linguagem de programação Python

2. Sua aplicação deve incluir os seguintes componentes: 

a. Modelagem de dados 
b. Fluxograma 
c. Deverá conter uma interface para o usuário navegar na aplicação 
d. Validações nos campos para ele não informar texto no lugar de número 
e. Usabilidade: ser uma aplicação fácil de navegar 
f. Linguagem de programação Python 
g. Utilize uma biblioteca para fazer a integrar a interface com a programação back-end (tkinter / flask) 
h. Validação de usuário (login e senha) 
i. Conexão com o banco de dados
j. Sessão de usuário  
k. Perfil de usuário (Administrador / Comum) 
l. Criptografia de senha (opcional)


Requisitos Específicos: 
1. Cadastro de produto / material no estoque: 
● Conter campo obrigatório para ser preenchido 

2. Cadastro de novo usuário: 
● Somente o usuário administrador pode cadastrar 

3. Visualização e Alertas: 
● Listagem de produtos abaixo de uma quantidade mínima colocar em 
destaque 

4. Segurança: 
● Mínimo 2 tipos de perfis (Administrador / Comum) 
● Somente administrador poderá cadastrar usuário 
● Login e senha para validar o usuário (Sessão de usuário) 
● Diferencial aplicar criptografia de senha 

5. Por que desenvolver um sistema de controle de estoque? 
Reflita sobre os fatores que levam uma empresa a contratar esse serviço. 
Isso o ajudará a focar suas soluções nos pontos críticos do processo. 

6. Qual o principal benefício ao digitalizar o controle de estoque? 
Considere não apenas o fato de uma rápida busca encontrar o produto e a 
disponibilidade em estoque, mas também a redução de papeis assinados 
por funcionários para retirar o produto minimizando os impactos 
ambientais. Isso pode inspirar soluções mais abrangentes. 

7. Quais são os prós e contras enfrentados? 
Pense em diferentes tipos de aplicações, cada uma terá o seu ponto positivo e terá suas desvantagens também, cabe a você mostrar que os 
pontos positivos superam os negativos. 

8. Quais são as barreiras ou desafios para implementar um sistema? 
Considere todos os aspectos possíveis, desde o Presidente da empresa 
querendo economizar dinheiro até um dos casos mais comuns que são os 
funcionários que não aceitam mudanças. 
Ao propor suas soluções, certifique-se de que cada uma aborde os seguintes 
aspectos: 
● O processo está sendo melhorado 
● As informações estão seguras 
● Os dados são confiáveis  
● Interface de visualização e alertas
